3. Applicant Workflow

Phase 1 — Registration & Onboarding
1
Visit FIRA Website (Public)
Views: Landing Page, About, Services, FAQ, Contact, Job Listings, Employer Partnership
2
Create Account
Clicks "Register" → fills name, email, phone, password, agrees to Terms → auto-creates as Applicant role
API: POST /api/auth { action: 'register', role: 'applicant' }
3
Complete Profile (Multi-Step Form)
View: My Profile → Personal Info, Education, Work Experience, Skills, Languages, Certifications, References, Documents, Trainings
Profile has formStep (0-9) and isComplete flag
▼
Phase 2 — Job Search & Application
4
Browse Jobs
View: Find Jobs → filter by country, category, search keyword. Sees public jobs only (visibility='public', status='open').
API: GET /api/jobs?public=true&country=...&category=...&search=...
5
View Job Details
View: Job Detail → sees title, description, requirements, benefits, skills, salary, location, agency info, slots available
API: GET /api/jobs/[id]
6
Apply for Job
Clicks "Apply" → creates Application record with status='applied', optionally fills cover letter and custom field responses
API: POST /api/applications { applicantId, jobOrderId, coverLetter, customResponses }
▼
Phase 3 — AI-Powered Enhancement
7
AI Resume Boost
View: AI Resume Boost → pastes current resume text + target job description → AI enhances the resume to better match the job
API: POST /api/ai/resume-enhance → stores result in ResumeEnhancement table
8
Track Applications
View: My Applications → sees all applied jobs with status (applied, screening, endorsed, accepted, deployed, rejected)
API: GET /api/applications?applicantId=[id]
▼
Phase 4 — Communication
9
Messaging
View: Messages → real-time messaging with agencies, FIRA staff, and other users. Can send/receive messages.
10
Notifications
Receives in-app notifications (bell icon in navbar) for: application status changes, new messages, endorsement updates
11
Account Settings
View: Settings → change password, update profile info, manage accessibility preferences

FeatureDetails

10. Service-Specific Flows

10a. AI Matching Service

1
Select Job Order
User (FIRA or Employer) selects a job order from dropdown
2
Run AI Matching
System analyzes job requirements/skills against all applicant profiles → calculates match score (0-100%), semantic score, matched skills, missing skills, explanation
API: POST /api/ai/match { jobOrderId } → returns ranked candidates
3
Review Results
Ranked list shows: applicant name, match score, matched skills (green tags), missing skills (red tags), AI explanation
4
Action
From results, user can navigate to applicant profile, create endorsement, or view full application

10b. AI Resume Enhancement Service

1
Paste Job Description
Applicant pastes the target job description text
2
Paste Current Resume
Applicant pastes their current resume text
3
Enhance
AI rewrites the resume to better match the job description. Returns enhanced text + changes summary.
API: POST /api/ai/resume-enhance → stores in ResumeEnhancement table
4
Review & Use
Applicant sees original vs enhanced side-by-side with highlighted changes. Can copy or use the enhanced version.

10c. Messaging Service

1
Open Messages
Available to ALL logged-in users. Shows conversation list on the left, message thread on the right.
2
Select/Create Conversation
Click existing conversation or start a new one. Conversations are between two users (peer-to-peer).
3
Send & Receive Messages
Real-time messaging (WebSocket-based via socket.io). Messages stored in database.
WebSocket: io('/?XTransformPort=3001') — real-time bidirectional

10d. Notification Service

1
Notification Triggers
System creates notifications for: new messages, application status changes, endorsement updates, new job postings near preferred country
2
In-App Display
Bell icon in navbar shows unread count badge. Clicking opens notification dropdown.
API: GET /api/notifications?userId=[id]
3
Mark as Read
Clicking a notification marks it as read and optionally navigates to the relevant page.
