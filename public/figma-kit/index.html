FIRA Design System

Figma Import Kit — 16 SVG Frames (8 categories × Light + Dark)

How to import into Figma:
1. Download all SVG files from this folder (or drag them directly from your file browser into Figma)
2. Each SVG file becomes its own Frame in Figma automatically
3. All elements are editable — colors, text, shapes, borders
4. Text labels serve as your reference catalogue (you can hide/delete them later)
Tip: Select all 16 SVGs → drag into Figma → they appear as 16 separate frames
